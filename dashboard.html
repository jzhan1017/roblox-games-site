The dashboard

One web page on the owner's computer that shows how the agent team is doing. Every number is saved when it happens, so you can see history, not just today.

The main questions it answers

Question What you see
Are players getting new things? How many changes made it into the live game
Did we fix bugs before adding features? Recent changes, colored red if a feature jumped ahead of a bug
Is anything broken for players right now? Errors from the live game, per hour
Is the game simple enough for a kid? A score: buttons on screen, how fast the first reward comes, lag
What is each agent doing? One box per agent: what it's working on and what it owes
Is work piling up? Tasks opened vs finished, per day
What did the autopilot do? Each number that went red, what the program did about it, and whether it worked
How much does it cost? AI usage this week, and cost per agent
How often did agents bother the owner? Every question they asked. This should go down.

Two more tabs

  • Playtests: each test session, what the bots saw, screenshots, and what got fixed.
  • Bugs: who found each bug (the owner, a bot, or the live game), and whether it was fixed.
