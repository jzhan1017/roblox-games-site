Playtesting and bugs

Tests can check the math. They can't tell you if the game feels broken. So bots play it.

How a playtest works

  1. The owner types /playtest and walks away from the computer.
  2. Roblox Studio opens, and bots join the game as players.
  3. The bots play nonstop: smash, grab candy, buy sticks, walk around.
  4. A playtester agent watches the bots, looks closer when something seems wrong, and takes screenshots.
  5. When time's up, every problem becomes a task with a screenshot. These tasks go first.

It only runs while the owner is away, because Studio takes over the screen.

Where bugs come from

  • The owner plays and reports.
  • Bots find them in playtests.
  • The live game sends its errors back automatically.

The rule for fixing a bug

Every fix comes with a test that would have caught the bug. That way the same bug can't come back unnoticed.

The goal: agents find bugs before the owner does.
