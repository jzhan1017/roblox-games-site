The agents

A team of Claude agents builds the game. Each one has a job, like people at a small studio.

Who does what

Agent Job
Scout Looks at the most popular Roblox games every day
Planner Turns ideas into tasks
Builders Write the game code, the screens, and add art and sound
Reviewers Check every change before it goes in
Playtester Plays the game and reports problems
Coach Checks the team is set up right

How one change happens

  1. A task is written down.
  2. A builder agent picks it up and makes the change.
  3. Three reviewers check it: Is it fun? Is the code good? Does it really work?
  4. Automatic tests run.
  5. If everything passes, it goes in. The owner then publishes it to the game.

How the team decides what to do

A program checks the team about once a minute and steers it:

  • Bugs come first. If something is broken, new features wait.
  • Don't run too fast. It adds or removes agents so the week's AI budget lasts all week.
  • Nothing sits. Every task gets done or dropped within a few hours.
  • Don't bother the owner. Agents make their own decisions. They only ask the owner for things like a login or a payment.

How they learn

When the owner corrects a mistake, it becomes a written rule. Every agent reads the rules before it starts, so the same mistake doesn't happen twice.
