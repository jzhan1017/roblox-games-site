Help out

You can work on this the same way the owner does, with your own Claude.

1. Set up

gh repo clone jzhan1017/roblox-games
cd roblox-games
./.setup

./.setup installs everything and tells you what's left. A few steps need you:

  • Accept the GitHub invite.
  • Log in to GitHub: gh auth login.
  • Install Roblox Studio.
  • Make your own Roblox API key. The steps are in docs/CONTRIBUTING.md.

2. Start Claude

claude

It reads the project's rules on its own. Then just ask, for example:

  • "What's left to set up?"
  • "Show me a task I could do."
  • "Build task #123 and open a pull request."
  • "Open the game in Studio so I can try my change."

3. Your change goes in

Your change gets the same reviews and tests as the agents' changes. Once it's in, it goes live the next time the owner publishes.
